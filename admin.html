Brand page editor

How this works (plain English):
  1. Pick a brand tab below.
  2. Change the text, prices, or pictures — what you see in the preview boxes is what the page will show.
  3. To add pictures from your phone, tap Add pictures and pick photos. Tap a picture's ★ to make it the big top image, × to remove one.
  4. When done, choose how to save:
    Download updated files — saves the new page info + pictures to your phone. Send them to Edison and he'll put them live.
    Publish live now — puts your changes on the website yourself within a few minutes (needs a one-time setup below).

One-time setup (do this once):
  1. On GitHub, open your profile → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token.
  2. Give it a name like "garage site editor", tick repo, generate, and copy the token.
  3. Paste it below with your GitHub name and site repository name. The token is stored only in this browser — it is never sent anywhere except GitHub when you publish.
